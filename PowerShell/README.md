# PowerShell and Windows Terminal

Portable setup for PowerShell 7, Starship, Windows Terminal, and Coreutils for
Windows. The configuration uses the Starship theme in
[`../starship/starship.toml`](../starship/starship.toml).

No PowerShell history, credentials, account names, machine-specific paths, or
generated Windows Terminal profile identifiers are included.

## Requirements

- Windows 11 or a Microsoft Dev Box
- Windows Package Manager (`winget`)
- Git

## Install

Clone this repository and run the bootstrap script:

```powershell
git clone https://github.com/wictorwilen/config.git
Set-Location .\config\PowerShell
.\install.ps1
```

The script:

1. Installs PowerShell, Windows Terminal, Starship, and Coreutils with `winget`.
2. Copies [`profile.ps1`](profile.ps1) to the current user's all-hosts
   PowerShell profile, backing up an existing profile first.
3. Copies the shared Starship configuration to `~\.config\starship.toml`.

Restart PowerShell after installation.

## Nerd Font

The prompt uses symbols that require **CaskaydiaCove Nerd Font**.

1. Download **Cascadia Code** from the
   [Nerd Fonts downloads page](https://www.nerdfonts.com/font-downloads).
2. Install the `CaskaydiaCoveNerdFont` font files.
3. Open Windows Terminal settings.
4. Under **Defaults > Appearance**, select
   **CaskaydiaCove Nerd Font**.

Alternatively, merge the `profiles.defaults` settings from
[`terminal-profile-defaults.jsonc`](terminal-profile-defaults.jsonc) into
Windows Terminal's `settings.json` (the root-level `profiles` object). Do not
replace the complete settings file, because generated WSL and Visual Studio
profiles vary between machines.

## Files intentionally not synchronized

- `Microsoft.PowerShell_profile.ps1` generated by Coreutils. Installing the
  `Microsoft.Coreutils` package creates the correct machine-local version.
- Windows Terminal's complete `settings.json`, because it contains generated
  profile identifiers and machine-specific profiles.
- PSReadLine command history.
